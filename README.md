# ML Mini Projects 🚀

A collection of beginner-friendly Machine Learning projects built using **Python**, **Scikit-Learn**, **Pandas**, and **Tkinter GUI**.

These projects were created to learn the complete ML workflow, including:

* Data Loading and Preprocessing
* Feature Selection
* Model Training
* Model Evaluation
* User-Friendly GUI Development
* Real-Time Predictions

---

# 📂 Projects Included

## 1️⃣ Diabetes Prediction System 🩺

### Description

A Machine Learning application that predicts whether a person is likely to be diabetic based on health-related parameters.

### Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* SVM (Support Vector Machine)
* StandardScaler
* Tkinter

### Input Parameters

* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI
* Diabetes Pedigree Function
* Age

### Output

* Diabetic
* Not Diabetic

# 🛠️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/ML-Mini-Projects.git
```

Move into the project directory:

```bash
cd ML-Mini-Projects
```

Install dependencies:

```bash
pip install pandas numpy scikit-learn
```
